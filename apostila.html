Contrato em C#

public sealed class CriarProdutoInput
{
    public string Nome { get; init; } = string.Empty;
    public string Categoria { get; init; } = string.Empty;
    public decimal Preco { get; init; }
    public int Estoque { get; init; }
}

public sealed class CriarProdutoPayload
{
    public required Produto Produto { get; init; }
}
Não use Produto diretamente como input: a entidade contém campos controlados pelo servidor e relacionamentos que não pertencem à operação de criação.
TipoResponsabilidade
ProdutoMapear o estado persistido pelo EF Core.
CriarProdutoInputDefinir somente os dados aceitos na criação.
CriarProdutoPayloadDefinir o resultado devolvido pela mutation.

Resolver de escrita

public async Task<CriarProdutoPayload> CriarProdutoAsync(
    CriarProdutoInput input,
    AppDbContext db,
    CancellationToken cancellationToken)
{
    Produto produto = new()
    {
        Nome = input.Nome.Trim(),
        Categoria = input.Categoria.Trim(),
        Preco = input.Preco,
        Estoque = input.Estoque
    };

    db.Produtos.Add(produto);
    await db.SaveChangesAsync(cancellationToken);

    return new CriarProdutoPayload { Produto = produto };
}

builder.Services
    .AddGraphQLServer()
    .AddQueryType<Query>()
    .AddMutationType<Mutation>()
    .AddProjections()
    .AddFiltering()
    .AddSorting();

Mutation com variável

mutation CriarProduto($input: CriarProdutoInput!) {
  criarProduto(input: $input) {
    produto {
      id
      nome
      preco
    }
  }
}

Checklist de entrega

  • dotnet test mostra oito testes aprovados.
  • A mutation válida retorna um identificador.
  • A query encontra o produto criado.
  • O caso inválido retorna código de erro.
  • A imagem loja-graphql:aula07 existe.
  • O endpoint /graphql funciona no contêiner.
